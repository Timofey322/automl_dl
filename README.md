# AutoML для временных рядов с использованием глубокого обучения

Годовой проект магистерской программы «Искусственный интеллект» НИУ ВШЭ.

## Информация о проекте

- **Тема № 17:** Предсказание стоимости акций
- **Автор:** Курлягд Тимофей Александрович
- **Куратор:** Дмитрий Янышев

## Цель

Разработать и исследовать AutoML-подход к прогнозированию стоимости акций по временным рядам с применением моделей глубокого обучения.

## Планируемые задачи

1. Собрать и подготовить исторические биржевые данные.
2. Выбрать метрики и схему валидации, исключающую утечку будущих данных.
3. Реализовать базовые модели прогнозирования.
4. Автоматизировать подбор архитектуры и гиперпараметров моделей глубокого обучения.
5. Сравнить модели и проанализировать результаты экспериментов.

## Статус

Проект находится на начальном этапе.
