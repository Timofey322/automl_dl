# AutoML для временных рядов с использованием глубокого обучения

Годовой проект магистерской программы «Искусственный интеллект» НИУ ВШЭ.

## Информация о проекте

- **Тема № 17:** Предсказание стоимости акций
- **Автор:** Курлянд Тимофей Александрович
- **Куратор:** Дмитрий Янышев

## Цель

Разработать и исследовать AutoML-подход к прогнозированию стоимости криптовалют по временным рядам с применением моделей глубокого обучения.

## Поддерживаемые тикеры

Система работает с четырьмя популярными криптовалютами с высокой капитализацией:

- **BTC-USD** — Bitcoin;
- **ETH-USD** — Ethereum;
- **BNB-USD** — BNB;
- **SOL-USD** — Solana.
